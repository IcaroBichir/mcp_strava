# strava-mcp

MCP server for Strava. Gives Claude access to your training data so you can ask questions, build reports, and track progress directly in conversation.

> **Work in progress.** This project is under active development. Watch the repo or check back soon.

---

## What it does

Connects Claude to your Strava account via the [Model Context Protocol](https://modelcontextprotocol.io). Runs locally — your data never leaves your machine.
